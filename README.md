# SafeWatch: Real-Time Fall Detection

A beginner computer vision project that aims to detect possible falls
from webcam or video input using Python, OpenCV, and pose estimation.

## My Goal

I am building this project in 30 days to learn:

- Python programming
- Computer vision
- OpenCV
- Pose estimation
- GitHub
- Basic AI project development

## Project Status

Day 1: Project repository created.

Day 2: OpenCV webcam feed working successfully.

 Day 3: Local video playback, portrait/landscape window support, and timestamped screenshot saving added.

- Day 4: Added video metadata, frame counter, playback time, and progress bar. 
## Note

This will be an educational project and not a medical or emergency-use system.
